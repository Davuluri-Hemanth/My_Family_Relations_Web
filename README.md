# My Family Relations — Global Web App (Vercel)

Browser-based family relations application using FastAPI + MongoDB Atlas.

## Deployment

This repository is prepared for Vercel:

- `frontend/` — browser UI
- `backend/main.py` — FastAPI API
- `api/index.py` — Vercel Python entry point
- `vercel.json` — routing configuration
- `requirements.txt` — Python dependencies

See `DEPLOY_VERCEL.md` for the no-credit-card deployment path.

Never commit `.env` or real credentials.
